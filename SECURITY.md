# Security policy

## Supported versions

The latest `2.x` release on npm receives security fixes.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's [security advisories](https://github.com/ix-xs/twitch.api/security/advisories/new),
or email **contact@ix-xs.dev**. Include a description, affected versions, and a
minimal reproduction if possible. Never include a real token or client secret.

You will get an acknowledgement, and a fix will be released as promptly as the
severity warrants, with credit unless you prefer to remain anonymous.
